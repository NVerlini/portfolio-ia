# Appunti

Note di studio, un file per argomento. Si scrive quello che ho letto o verificato. Un'intestazione vuota resta vuota finché non c'è un appunto vero.

La prima nota, da compilare nella settimana 1, è [ai-act-alfabetizzazione.md](ai-act-alfabetizzazione.md): una pagina sull'alfabetizzazione prevista dall'articolo 4 dell'AI Act. Il file ha solo le intestazioni e il link alla FAQ della Commissione europea. Il testo lo aggiungo io dopo la lettura.

Per una nota nuova, copia quel file, cambia il titolo e tieni la stessa abitudine: fonti in cima, affermazioni solo se sai da dove vengono.
