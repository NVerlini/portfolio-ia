# Certificati

Qui metto i PDF e gli screenshot dei certificati, quando un percorso è concluso. Lo stato aggiornato (in corso o da iniziare) resta nella tabella del [README principale](../README.md#certificazioni). Finché un corso non è finito, il file non c'è.

Prima di caricare un file:

- togli i metadati: autore e percorso locale del PDF, dati EXIF dello screenshot, nome del computer;
- oscura codice fiscale, data di nascita, indirizzo, numero di documento, telefono ed email, se compaiono;
- nome e cognome possono restare, se vuoi che il certificato sia riconducibile a te.

La scheda da compilare insieme al file è [TEMPLATE.md](TEMPLATE.md). Non è un certificato: è la lista di controllo per pubblicarne uno.
