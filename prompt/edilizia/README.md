# Prompt — edilizia

Prompt nati dal cantiere: rapportini di giornata, elenchi di lavorazioni, bozze di preventivo, messaggi alla squadra o al committente.

Ogni testo che esce da un assistente va riletto da chi conosce il lavoro e, nel caso di un preventivo, da chi lo firma. Qui non ci sono ancora prompt archiviati.
