# Titolo del prompt

## Obiettivo

Che cosa deve produrre l'assistente, in una frase.

## Contesto

Chi sono in questo caso, per chi è il lavoro, qual è la situazione reale. Solo fatti che posso sostenere.

## Prompt

```text
Incolla qui il prompt intero, con ruolo, contesto, vincoli e formato di uscita.
```

## Strumento usato

Nome dell'assistente e, se conta, la modalità usata nel test.

## Risultato

Che cosa ha risposto. Incolla il testo utile, o riassumilo senza abbellirlo. Se non hai ancora provato il prompt, lascia questo campo vuoto.

## Cosa ho migliorato

Che cosa hai cambiato nel prompt dopo aver letto la risposta. Prima del test, scrivi solo le scelte già fatte in questa versione.
