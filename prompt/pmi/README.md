# Prompt — PMI

Prompt pensati per piccole e medie imprese, oltre ai mestieri da cui parto. Gli ambiti aperti sono commercio, studi professionali, turismo e manifattura.

Un prompt entra qui quando il caso è di un'attività, anche se l'esempio nasce da un settore che conosco meno: nel contesto va scritto che cosa so e che cosa sto solo ipotizzando.

Qui non ci sono ancora prompt archiviati.
