# Prompt

Qui raccolgo i prompt che provo sul serio, uno per file. Ogni scheda segue [TEMPLATE.md](TEMPLATE.md): obiettivo, contesto, prompt, strumento, risultato, che cosa ho migliorato, data.

Il risultato si compila dopo il test. Se l'assistente non è ancora stato interrogato, il campo resta vuoto: non si incolla una risposta immaginata.

Le cartelle dividono i contesti in cui lavoro, o in cui voglio lavorare:

- [sci](sci/) — scuola sci e allenamento, sci alpino
- [edilizia](edilizia/) — cantiere, rapportini, preventivi
- [web3](web3/) — community e DAO
- [pmi](pmi/) — commercio, studi professionali, turismo, manifattura

Per aggiungere un prompt: copia `TEMPLATE.md` nella cartella giusta e rinomina il file in modo che si capisca il caso (`piano-allenamento-gigante.md`, non `prompt1.md`).
